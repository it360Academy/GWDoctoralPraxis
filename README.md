Multiclass Machine Learning Framework | NIS 2021–2023

This project implements a leakage-controlled, cross-year supervised multiclass machine learning framework to investigate whether secondary diagnosis codes (DX2–DX25) discriminate the principal diagnosis (DX1) across 15 vascular, infectious, and oncological disease categories using the U.S. National Inpatient Sample (NIS) from 2021 to 2023. The study follows a strict temporal validation strategy, training models on 2021 data, selecting models using 2022 data, and conducting independent final testing on 2023 data. Secondary ICD-10-CM diagnosis codes are transformed into three-character category features using multi-hot encoding, with the feature vocabulary established exclusively from the training dataset. Strict phenotype-level masking removes diagnosis codes directly associated with any target disease to minimize information leakage. The framework evaluates Logistic Regression, Random Forest, LightGBM, and XGBoost, applying balanced class weighting to address substantial differences in disease prevalence. The configuration also includes optional demographic and admission-related predictors for sensitivity analysis, with hyperparameter tuning disabled by default.

The research pipeline emphasizes reproducibility, statistical validation, and transparent model evaluation. It uses a fixed random seed of 42, processes large inpatient datasets in chunks of 200,000 records, and supports checkpointing for efficient execution. Model performance is evaluated using 1,000 bootstrap resamples with 95% confidence intervals and 200 permutation-based negative-control tests. Primary evaluation thresholds include macro AUROC-OVR ≥ 0.70, macro Matthews Correlation Coefficient (MCC) ≥ 0.30, and balanced accuracy ≥ 0.30, alongside individual disease-level performance criteria and complete coverage of all 15 disease categories. Additional measures include a minimum positive predictive value lift of 2.0 for low-prevalence diseases and strict separation between training, validation, and testing datasets. The performance thresholds are provisional and require validation against appropriate published benchmarks. This configuration provides a structured and reproducible foundation for evaluating diagnostic-code relationships, controlling information leakage, and assessing machine learning performance across multiple years of national inpatient data.
